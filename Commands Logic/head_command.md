# head Command Implementation

## Purpose

The `head` command is used to display the first few lines of a text file. By default, it prints the first **10 lines**, but the user can specify a different number of lines as an optional argument.

---

## Function Signature

```cpp
void head(const std::vector<std::string>& args)
```

The function receives a vector of command-line arguments where:

- `args[0]` → Path of the file to be displayed.
- `args[1]` *(optional)* → Number of lines to display.

---

## Implementation Logic

### 1. Validate Input

```cpp
if(args.empty())
{
    std::cerr << "head: missing filename\n";
    return;
}
```

- Checks whether a filename has been supplied.
- If no filename is provided, an error message is displayed.
- The function exits immediately.

---

### 2. Open the File

```cpp
std::ifstream file(args[0]);
```

An input file stream is created to open the specified file in read mode.

---

### 3. Verify File Access

```cpp
if(!file)
{
    std::cerr << "head: cannot open file\n";
    return;
}
```

If the file cannot be opened, an error message is displayed and the function terminates.

---

### 4. Set the Number of Lines

```cpp
size_t n = 10;
```

The command defaults to displaying the first **10 lines**, matching the behavior of the Linux `head` command.

If the user provides a second argument:

```cpp
if(args.size() > 1)
{
    n = std::stoi(args[1]);
}
```

- The second argument is converted from a string to an integer using `std::stoi()`.
- This value determines how many lines will be printed.

---

### 5. Read and Display the File

```cpp
std::string line;

for(size_t i = 0; i < n; i++)
{
    if(std::getline(file, line))
    {
        std::cout << line << '\n';
    }
    else
    {
        break;
    }
}
```

The function reads one line at a time using `std::getline()`.

- If a line is successfully read, it is printed to the terminal.
- If the end of the file is reached before `n` lines have been displayed, the loop terminates.

---

### 6. Exception Handling

```cpp
catch(const std::exception& e)
{
    std::cerr
        << "head: "
        << e.what()
        << '\n';
}
```

Any exception (such as an invalid numeric argument passed to `std::stoi()`) is caught and an appropriate error message is displayed.

Example:

```
head: invalid stoi argument
```

or

```
head: cannot open file
```

## Time Complexity

| Operation | Complexity |
|-----------|------------|
| Open file | O(1) |
| Read first *n* lines | O(n) |

where **n** is the number of lines requested (or fewer if the file ends earlier).

---

## Example Usage

### Display the First 10 Lines

```
head notes.txt
```

Output:

```
Line 1
Line 2
...
Line 10
```

---

### Display the First 5 Lines

```
head notes.txt 5
```

Output:

```
Line 1
Line 2
Line 3
Line 4
Line 5
```

---

### Missing Filename

```
head
```

Output:

```
head: missing filename
```

---

### File Does Not Exist

```
head test.txt
```

Output:

```
head: cannot open file
```

---

### Invalid Line Count

```
head notes.txt abc
```

Output:

```
head: invalid stoi argument
```

(depending on the exception message generated by the C++ standard library)

- `std::cout`
- `std::cerr`

---

## Limitations

- Supports only one input file.
- Displays only the beginning of a file.
- Does not support Linux options such as `-n`, `-q`, `-v`, or reading multiple files.
- Assumes the second argument is a valid integer; invalid input results in an exception.
- Supports only positive line counts.

---

## Summary

The `head` command implementation displays the first few lines of a text file by reading it sequentially with `std::getline()`. It defaults to showing the first **10 lines** but allows the user to specify a custom line count. The implementation includes input validation, file access checks, configurable output length, and exception handling, providing a simple and efficient file preview utility for the custom terminal application.
