# mv Command Implementation

## Purpose

The `mv` command is used to move or rename a file or directory. It utilizes the C++17 `<filesystem>` library to relocate a file or change its name, similar to the Linux `mv` command.

---

## Function Signature

```cpp
void mv(const std::vector<std::string>& args)
```

The function receives a vector of command-line arguments where:

- `args[0]` → Source file or directory.
- `args[1]` → Destination path or new name.

---

## Implementation Logic

### 1. Validate Input

```cpp
if (args.size() < 2)
{
    std::cerr << "mv: missing source or destination\n";
    return;
}
```

- Ensures that both the source and destination paths are provided.
- If either argument is missing, an error message is displayed and the function terminates.

---

### 2. Move or Rename the File

```cpp
std::filesystem::rename(args[0], args[1]);
```

The `std::filesystem::rename()` function performs the requested operation.

Depending on the destination path, it can:

- Rename a file.
- Rename a directory.
- Move a file to another directory.
- Move a directory to another location.

If the operation cannot be completed, a filesystem exception is thrown.

---

### 3. Display Success Message

```cpp
std::cout << "Moved/Renamed successfully.\n";
```

If the operation completes successfully, a confirmation message is displayed.

---

### 4. Handle Filesystem Exceptions

```cpp
catch (const std::filesystem::filesystem_error& e)
{
    std::cerr << "mv: " << e.what() << '\n';
}
```

This catch block specifically handles exceptions generated by filesystem operations, such as:

- Source file not found.
- Destination already exists (platform dependent).
- Permission denied.
- Invalid path.

---

### 5. Handle General Exceptions

```cpp
catch (const std::exception& e)
{
    std::cerr << "mv: " << e.what() << '\n';
}
```

Any other standard C++ exceptions are caught and reported to prevent program termination.

## Example Usage

### Rename a File

```
mv notes.txt report.txt
```

Output:

```
Moved/Renamed successfully.
```

---

### Move a File

```
mv report.txt Documents/report.txt
```

Output:

```
Moved/Renamed successfully.
```

---

### Rename a Directory

```
mv Projects OldProjects
```

Output:

```
Moved/Renamed successfully.
```

---

### Missing Arguments

```
mv notes.txt
```

Output:

```
mv: missing source or destination
```

---

### Source File Does Not Exist

```
mv file.txt newfile.txt
```

Output (example):

```
mv: filesystem error: cannot rename...
```

(The exact message depends on the operating system.)

## C++ Features Used

- `std::vector`
- `std::filesystem::rename()`
- `std::filesystem::filesystem_error`
- Exception handling (`try-catch`)
- `std::cout`
- `std::cerr`

---

## Limitations

- Supports only a single source and a single destination.
- Does not support moving multiple files simultaneously.
- Does not provide overwrite confirmation.
- Behavior when the destination already exists depends on the operating system and filesystem implementation.
- Does not support Linux options such as `-i` (interactive), `-f` (force), `-n` (no overwrite), or `-v` (verbose).

---

## Summary

The `mv` command implementation validates the source and destination paths, uses `std::filesystem::rename()` to move or rename files and directories, reports successful operations, and handles filesystem-related exceptions gracefully. It provides a simple and portable implementation of the classic `mv` utility for the custom terminal application.
