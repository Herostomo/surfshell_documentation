# tail Command Implementation

## Purpose

The `tail` command is used to display the last few lines of a text file. By default, it prints the last **10 lines**, but the user can specify a different number of lines as an optional argument.

---

## Function Signature

```cpp
void tail(const std::vector<std::string>& args)
```

The function receives a vector of command-line arguments where:

- `args[0]` → Path of the file to be displayed.
- `args[1]` *(optional)* → Number of lines to display.

---

## Implementation Logic

### 1. Validate Input

```cpp
if(args.empty())
{
    std::cerr << "tail: missing filename\n";
    return;
}
```

- Checks whether the user has supplied a filename.
- If no filename is provided, an error message is displayed.
- The function exits immediately.

---

### 2. Open the File

```cpp
std::ifstream file(args[0]);
```

An input file stream is created to open the specified file in read mode.

---

### 3. Verify File Access

```cpp
if(!file)
{
    std::cerr << "tail: cannot open file\n";
    return;
}
```

If the file cannot be opened, an error message is displayed and execution terminates.

---

### 4. Determine the Number of Lines

```cpp
size_t n = 10;
```

By default, the command displays the last **10 lines**.

If a second argument is provided:

```cpp
if(args.size() > 1)
{
    n = std::stoi(args[1]);
}
```

- The value is converted from a string to an integer using `std::stoi()`.
- This determines how many lines will be displayed from the end of the file.

---

### 5. Read the Entire File

```cpp
std::vector<std::string> lines;
std::string line;

while(std::getline(file, line))
{
    lines.push_back(line);
}
```

Unlike the `head` command, `tail` must determine the final lines of the file.

Therefore:

- Every line is read using `std::getline()`.
- Each line is stored in a `std::vector<std::string>`.

---

### 6. Compute the Starting Position

```cpp
size_t start = 0;

if(lines.size() > n)
{
    start = lines.size() - n;
}
```

The starting index is calculated as follows:

- If the file contains more than **n** lines, display only the last **n**.
- Otherwise, display the entire file.

---

### 7. Display the Last Lines

```cpp
for(size_t i = start; i < lines.size(); i++)
{
    std::cout << lines[i] << '\n';
}
```

The function prints all lines beginning at the calculated starting position until the end of the vector.

---

### 8. Exception Handling

```cpp
catch(const std::exception& e)
{
    std::cerr
        << "tail: "
        << e.what()
        << '\n';
}
```

Any exception (such as an invalid numeric argument passed to `std::stoi()`) is caught and an appropriate error message is displayed.

Example:

```
tail: invalid stoi argument
```

or

```
tail: cannot open file
```

## Time Complexity

| Operation | Complexity |
|-----------|------------|
| Read entire file | O(m) |
| Display last *n* lines | O(n) |

where:

- **m** = Total number of lines in the file.
- **n** = Number of lines requested.

Overall complexity: **O(m)**.

## Example Usage

### Display the Last 10 Lines

```
tail notes.txt
```

Output:

```
Last Line - 9
Last Line - 8
...
Last Line
```

---

### Display the Last 5 Lines

```
tail notes.txt 5
```

Output:

```
Line 96
Line 97
Line 98
Line 99
Line 100
```

---

### Missing Filename

```
tail
```

Output:

```
tail: missing filename
```

---

### File Does Not Exist

```
tail test.txt
```

Output:

```
tail: cannot open file
```

---

### Invalid Line Count

```
tail notes.txt abc
```

Output:

```
tail: invalid stoi argument
```

(depending on the exception generated by the C++ standard library)

## Limitations

- Reads the **entire file into memory** before displaying the last lines.
- May consume significant memory for very large files.
- Supports only one input file.
- Does not support Linux options such as `-f` (follow mode), `-c`, or multiple files.
- Assumes the second argument is a valid positive integer.

---

## Summary

The `tail` command implementation displays the last few lines of a text file by reading the entire file into a `std::vector<std::string>`, calculating the starting position of the requested output, and printing the final **n** lines. It defaults to displaying the last **10 lines**, supports a user-defined line count, and includes input validation, file access checks, and exception handling, providing a straightforward implementation of the classic `tail` utility for the custom terminal application.
